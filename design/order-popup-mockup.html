4 — Настройка в Settings → Paper trading → «Опасные шорткаты» по умолчанию выключено

⚡ Опасные шорткаты

Жесты, отправляющие ордер без подтверждения. В live режиме крайне внимательно.
Shift+клик в стакане = мгновенный market опасно
Клик с зажатым Shift по строке стакана отправляет market-ордер без открытия формы. Сторона — противоположна типу строки (bid → Sell, ask → Buy). Объём берётся из последней использованной в popup'е цифры, либо 0.001 BTC если ещё не использовалась.

После включения: видно бейдж ⚡ shift-click в Status Bar, в tooltip строки стакана появляется упоминание жеста, при первом срабатывании будет учебный confirm-toast.
B / S = quick market опасно
Клавиши B и S открывают popup с уже подставленным market-ордером и выделенной qty. Один Enter — и ордер отправлен. Видно что отправляешь, но один лишний нажатый Enter может стоить.

5 — Учебный toast при первом Shift+click страховка от «включил и забыл»

Появляется при первом срабатывании жеста после включения опции. Дальше — без подтверждения, до отключения. Также можно вызвать «Показать справку повторно» из Settings.
⚡ Включён shift-clickпервый раз
Жест ⇧ + клик по строке стакана отправляет market ордер без подтверждения. Этот раз — confirm. Дальше — сразу.

Сейчас: Sell 0.10 BTC @ market (~ 7,366 USDT).
Что страхует пользователя:
1. Опция выключена по умолчанию — нельзя «случайно нажать Shift и купить» пока сам не включил.
2. После включения — постоянный бейдж в Status Bar.
3. Tooltip на hover показывает жест в момент когда курсор над строкой.
4. Первое срабатывание — учебный toast (вот этот).
5. Из toast можно сразу отключить фичу обратно.
6. В Settings → «Сбросить кнопки опасных шорткатов» — возвращает все toast'ы заново (если переустановил себя и хочешь снова увидеть подсказку).

6 — F9 и кнопка «📝 Новый ордер» в тулбаре путь без клика по стакану

Открывают тот же popup, но без привязки к строке. Позиционируется в центре активной chart-ячейки, дефолты: Market, активный символ, последний qty. Сторона не выбрана — пользователь явно тыкает Buy или Sell, чтобы избежать случайностей.
F9 / кнопка «Новый ордер» Popup появляется по центру активной chart-ячейки. Сторона не выбрана — пользователь должен явно выбрать Buy/Sell. Type=Market по умолчанию.

7 — Как закрывается popup

Esc
Закрытие без отправки.
Клик мимо popup'а
Закрытие. Клик по другой строке стакана — закрывает текущий и открывает новый с новой ценой.
После отправки ордера
Автозакрытие. В журнале появляется лог-событие «order placed: ...». Popup можно открыть снова за пару секунд если передумал.
Через 30 сек бездействия
Автозакрытие (настраиваемо). Чтобы не висел случайный popup пока ты переключился на другое окно.
