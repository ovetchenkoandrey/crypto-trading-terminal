# Прибыльная внутридневная стратегия для крипты (май 2026)

**Дата постановки:** 28.05.2026
**Роль исполнителя:** AI-исследователь и аналитик финансовых рынков в роли практикующего дейтрейдера с 10+ лет опыта на криптовалютных рынках, специализирующегося на краткосрочных алгоритмических стратегиях (scalping / intraday). Глубокая экспертиза в техническом анализе (price action, объёмы, индикаторы, market microstructure), понимание ончейн-метрик, фандинга, ликвидаций и поведения маркет-мейкеров на CEX (Binance, Bybit, OKX). Умеет переводить торговую логику в формализованный псевдокод, готовый к роботизации.

---

## Что нужно сделать?

**Описание задачи:** Разработать прибыльную внутридневную торговую стратегию для криптовалютного рынка, работающую на таймфреймах 1m / 5m / 15m. Стратегия должна быть основана преимущественно на техническом анализе (с возможным дополнением фундаментальными/ончейн-сигналами), актуальна на состояние рынка май 2026, рассчитана на средний риск и постепенный разгон депозита, с допустимым контролируемым усреднением. Конечная цель — полный автопилот (запуск через робота без ручного вмешательства).

Результат оформить в **трёх форматах**:
1. **`strategy.md`** — структурированное техническое описание стратегии (правила входа/выхода, риск-менеджмент, фильтры, параметры).
2. **`strategy.html`** — красивая одностраничная HTML-презентация в визуальном стиле «Electric Lime / Inter / Dark» (тёмная база + лаймовый акцент), с понятным описанием, схемами входов и примерами сделок. Один файл, без внешних зависимостей.
3. **`build-bot.prompt.md`** — готовый промпт для вставки в другой чат (Claude Code / ChatGPT), по которому AI-кодер соберёт работающего робота. Промпт должен содержать всё необходимое: стек, архитектуру, биржу/API, формализованную логику, требования к бэктесту и логированию.

**Job Story:** Когда у меня есть депозит на крипте и я хочу его аккуратно разогнать без сидения у монитора, я хочу получить готовую к роботизации внутридневную стратегию со средним риском и формализованными правилами, чтобы запустить её в автопилоте, иметь предсказуемый профиль доходности/просадки и не зависеть от ручных решений.

---

## Зачем это нужно?

**Проблема:** Большинство публичных стратегий либо устарели (заточены под рынок 2021–2023, когда работали другие режимы волатильности и ликвидности), либо размытые («покупай на отскоке от уровня»), либо нереализуемы в коде без додумывания. Ручной интрадей съедает время и эмоции, дисциплина проседает. Нужна формализованная, актуальная стратегия, которую можно запустить роботом и забыть.

**Ценность:** Получить рабочий торговый каркас, который:
- учитывает реалии рынка мая 2026 (текущая волатильность BTC/ETH/альтов, доминирование, поведение после халвинга 2024, текущий режим фандинга и ликвидаций);
- даёт положительное матожидание при среднем риске (целевая просадка не критична для депозита);
- однозначно переводится в код без интерпретаций;
- сразу готова к деплою через промпт-сборку.

## Контекст и ограничения

- **Инструмент:** криптовалюты (фокус на ликвидные пары — BTC/USDT, ETH/USDT, топ-альты на perpetual futures или spot — исполнитель выбирает и обосновывает).
- **Таймфреймы:** 1m / 5m / 15m (исполнитель выбирает основной + подтверждающий).
- **Профиль риска:** средний. Допускается контролируемое усреднение (с ограничением по количеству шагов и максимальной экспозиции).
- **Целевое решение:** полный автопилот, без ручных подтверждений сделок.
- **Актуальность:** стратегия должна учитывать рыночные условия именно на май 2026 (волатильность, доминирование BTC, поведение after-halving cycle, регуляторный фон, ETF-потоки, фандинг).
- **Биржа:** по умолчанию Bybit (проект уже работает с Bybit spot/linear — см. контекст проекта), но можно обосновать другой выбор.
- **Стек робота:** на усмотрение исполнителя, но с прицелом на простую интеграцию (Python + ccxt / pybit, или Node.js — обосновать).
- **Дедлайн:** ASAP, одна итерация.

## Ресурсы и источники

- **Веб-ресерч обязателен.** Использовать актуальные материалы (2025–2026): аналитика CoinGlass, Coinalyze, TradingView idea-feed, статьи на Crypto Twitter (X), отчёты Glassnode/CryptoQuant, форумы quant-сообщества.
- **Источники по теханализу:** классика (price action, VWAP, ATR, объёмные профили, order flow) + современные подходы (liquidity sweeps, ICT-концепты, funding-arbitrage, ликвидационные каскады).
- **Собственная экспертиза модели** по микроструктуре крипторынка, по behavioral patterns (азиатская/европейская/американская сессии), по фандингу и ликвидациям.
- **Контекст проекта:** репозиторий `C:\Claude\Trading app` — уже есть UI с графиками, мозаикой и индикаторами; стратегия должна быть совместима по логике (Bybit, свечные данные).

## Критерии приёмки

**Образ идеального результата:** Получить пакет из трёх документов уровня внутреннего research-меморандума хедж-фонда + питч-страницы продукта. Стратегия описана так, что senior-квант сразу скажет «понятно, можно кодить», а не «расскажи подробнее, что значит вход». HTML-страница выглядит как продуктовый лендинг в стиле Linear/Vercel (тёмный фон, лаймовый акцент, чистая типографика Inter, схемы и примеры сделок). Промпт для робота — самодостаточный, по нему второй чат соберёт MVP без уточняющих вопросов.

- [ ] Стратегия конкретна: указаны точные таймфреймы, инструменты, индикаторы с параметрами, условия входа/выхода/стопа/тейка, правила усреднения с лимитами
- [ ] Описан риск-менеджмент: % риска на сделку, max drawdown, max позиций одновременно, правило отключения после серии убытков
- [ ] Стратегия обоснована применительно к маю 2026: явно указано, какие рыночные условия она эксплуатирует и почему работает сейчас (а не в 2021)
- [ ] Минимум 3 ссылки на актуальные внешние источники (статьи / данные 2025–2026), подтверждающие тезисы
- [ ] Приведены ожидаемые метрики: примерный winrate, R/R, частота сделок, ожидаемая просадка (с оговоркой «по логике стратегии», без гарантий)
- [ ] Описан как минимум один пример сделки от и до (с числами: цена входа, стоп, тейк, размер позиции)
- [ ] `strategy.md` — структурирован, читается за 5–7 минут, содержит все правила без воды
- [ ] `strategy.html` — один файл, без внешних CDN/скриптов, тёмная тема + лаймовый акцент, Inter, адаптив, есть визуальные схемы входов (можно SVG/CSS)
- [ ] `build-bot.prompt.md` — содержит: стек, архитектуру модулей, API биржи, формализованную торговую логику в псевдокоде, требования к бэктесту, к логированию, к конфигу, к обработке ошибок и реконнектам
- [ ] Все три файла согласованы между собой (одна и та же логика, без расхождений)

## Out of Scope — что делать НЕ нужно

- Не разрабатывать сам код робота — только промпт для сборки
- Не делать HFT/арбитраж на миллисекундах — это другой класс инфраструктуры
- Не предлагать стратегии на дневных/недельных таймфреймах
- Не давать «гарантии прибыли» и не использовать маркетинговый булшит («100% winrate», «секрет китов»)
- Не описывать ручные стратегии, требующие постоянного присутствия трейдера
- Не использовать платные/закрытые индикаторы, которые невозможно реализовать в коде
- Не интегрировать стратегию в существующий UI проекта `Trading app` — это отдельная задача
